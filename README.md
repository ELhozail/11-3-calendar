# البرنامج السنوي – الحادي عشر 3

هذه النسخة مبنية من جديد من ملف Excel المرفق `יא3 גנט(1).xlsx`.

## ما يحتويه الموقع
- تقويم شهري حقيقي من أغسطس 2026 حتى يوليو 2027
- الموعد القادم مع عدّاد أيام
- تصفية حسب: امتحان، مِגן، بجروت، عطلة/مناسبة، فعالية، أهالٍ/شهادات
- بحث
- قائمة سنوية للمواعيد
- الضغط على الحدث يفتح تفاصيله
- يحتفظ بالنص الأصلي من Excel للأحداث المكتوبة بالعبرية
- مشاركة عبر واتساب

## رفع الموقع على GitHub Pages
1. أنشئ مستودعًا باسم `11-3-calendar`
2. ارفع: index.html, styles.css, script.js, events.json
3. Settings → Pages
4. اختر Deploy from a branch
5. اختر main و /root
6. Save

## تعديل موعد
عدّل ملف `events.json`.
